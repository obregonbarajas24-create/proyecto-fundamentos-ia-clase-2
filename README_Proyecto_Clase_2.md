# Proyecto Clase 5: Rosa comprueba que su asistente responde con el manual

## Información del proyecto
- **Tema:** RAG, modelos y alucinaciones.
- **Rol:** Rosa (Operaciones).
- **Empresa:** Distribuidora Valle Verde.
- **Objetivo:** Comprobar que un asistente de inteligencia artificial responde utilizando el manual de procesos y no inventa información.

## Descripción
En este proyecto se utiliza un asistente de inteligencia artificial para responder preguntas sobre el Manual de Procesos de Operaciones de Distribuidora Valle Verde, versión 3.2.

Se comprueba que las respuestas coincidan con el manual, indicando la sección y la página correspondiente.

## Prompt utilizado
Actúa como un asistente especializado en operaciones de bodega. Responde exclusivamente con la información del Manual de Procesos de Operaciones. No inventes información ni hagas suposiciones. Indica la sección y página de donde obtuviste cada respuesta. Si la información no aparece en el manual, responde: "No se especifica en el manual".

## Actividades realizadas
1. Elaboración de un prompt para consultar el manual.
2. Preparación de tres preguntas para un nuevo trabajador.
3. Comparación de las respuestas del asistente con el manual.
4. Realización de una pregunta de control cuya respuesta no aparece en el documento.
5. Revisión de posibles errores, contradicciones y suposiciones.

## Material utilizado
**Manual de Procesos de Operaciones de Distribuidora Valle Verde, versión 3.2.**

[Consultar manual en Google Drive](https://drive.google.com/file/d/1kClSvUghXzRYm38HdlOD-OZBEA3cweoX/view?usp=drive_link)

## Resultados
Se busca comprobar que el asistente:
- Utilice información respaldada por el manual.
- Indique las fuentes de sus respuestas.
- Reconozca cuando no encuentra información.
- Evite inventar datos o procedimientos.

## Conclusión
Este proyecto demuestra la importancia de verificar las respuestas de la inteligencia artificial con documentos confiables. Un asistente debe reconocer sus límites y no presentar información inventada como si fuera verdadera.
